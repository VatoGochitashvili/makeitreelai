# Background footage

Drop gameplay clips in here (`.mp4`, `.mov`, `.webm`, `.mkv`) and they become
choices in the Studio for the split-screen and brainrot formats. They're picked
up on server start, so restart after adding files.

A good background is:

- **vertical or at least tall enough to crop** — it gets cropped to 9:16
- **2–10 minutes long** — clips start at a random point, so a longer file means
  ten clips from one run don't all open on the same frame
- **silent or ignorable** — the audio is dropped; the clip's own audio plays
- **constantly moving with no story** — parkour, obstacle courses, driving.
  Anything with its own plot competes with the narration

Use footage you recorded or that you're licensed to use. Gameplay ripped from
someone else's video is their copyright, and platforms do match it.

Files here are shared by everyone on this server. Per-user footage uploaded
through the Studio lives in `.data/backgrounds/` instead.
